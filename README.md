# 🎮 Remote Control System

ระบบควบคุมระยะไกลผ่านเว็บ - เข้าถึงได้จากทุก IP

## การติดตั้ง

### 1. ติดตั้ง dependencies
```bash
cd c:/xampp/htdocs/remote-control
npm install
```

### 2. เริ่มเซิร์ฟเวอร์
```bash
npm start
```

เซิร์ฟเวอร์จะรันที่ `http://0.0.0.0:3000` ซึ่งสามารถเข้าถึงได้จากทุก IP

## การใช้งาน

### การเข้าถึงเว็บควบคุม
เปิดเว็บเบราว์เซอร์แล้วไปที่:
- `http://localhost:3000` (ถ้าอยู่บนเครื่องเดียวกัน)
- `http://<IP-ADDRESS>:3000` (ถ้าเข้าจากเครื่องอื่น)

### การเชื่อมต่อเครื่องเป้าหมาย (Target)
บนเครื่องที่ต้องการควบคุม:

```bash
# รัน client script
node client.js

# หรือระบุ server URL ถ้าไม่ใช่ localhost
SERVER_URL=http://<SERVER-IP>:3000 node client.js
```

### ฟีเจอร์ควบคุม

- **🔒 ล็อคหน้าจอ** - ล็อคหน้าจอเครื่องเป้าหมาย
- **⭕ ปิดเครื่อง** - ปิดเครื่องเป้าหมาย
- **🔄 เริ่มใหม่** - รีสตาร์ทเครื่องเป้าหมาย
- **📸 ถ่ายหน้าจอ** - ถ่ายภาพหน้าจอ (ต้องติดตั้งเพิ่มเติม)
- **🌐 เปิดเว็บ** - เปิดเว็บไซต์บนเครื่องเป้าหมาย
- **💬 แสดงข้อความ** - แสดงข้อความแจ้งเตือน
- **🔊 เพิ่ม/ลดเสียง** - ควบคุมระดับเสียง
- **🔇 ปิดเสียง** - ปิดเสียงทั้งหมด
- **Custom Command** - ส่งคำสั่ง terminal ที่กำหนดเอง

## การตั้งค่า Firewall

ถ้าไม่สามารถเข้าถึงจากเครื่องอื่นได้ ต้องเปิด port 3000:

### Windows Firewall
```powershell
New-NetFirewallRule -DisplayName "Remote Control" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
```

### Linux
```bash
sudo ufw allow 3000
```

## ความปลอดภัย

⚠️ **ระบบนี้ออกแบบมาสำหรับการใช้งานในเครือข่ายที่เชื่อถือได้เท่านั้น**
- ไม่มีระบบ authentication
- ควรใช้ใน LAN เท่านั้น
- ไม่ควรเปิดเผยต่ออินเทอร์เน็ตสาธารณะโดยตรง

## การแก้ไขปัญหา

### ไม่สามารถเชื่อมต่อจากเครื่องอื่นได้
1. ตรวจสอบว่า Firewall ไม่ได้บล็อก port 3000
2. ตรวจสอบ IP address ของเซิร์ฟเวอร์
3. ใช้ `ipconfig` (Windows) หรือ `ifconfig` (Linux/Mac) เพื่อดู IP

### Client เชื่อมต่อไม่ได้
1. ตรวจสอบว่าเซิร์ฟเวอร์กำลังรันอยู่
2. ตรวจสอบ SERVER_URL ให้ถูกต้อง
3. ตรวจสอบการเชื่อมต่อเครือข่าย
